BikeNetLib |version| documentation
===================================

The Python package ``bikenetlib`` is BikeNetKit's core utility package. It offers general utilities for working with bicycle networks, which also forms the core of many upstream packages in the BikeNetKit family, like `GrowBikeNet <https://github.com/BikeNetKit/GrowBikeNet>`__, `FixBikeNet <https://github.com/BikeNetKit/FixBikeNet>`__, or `LinkBikeNet <https://github.com/BikeNetKit/LinkBikeNet>`__. It is hosted on `Github <https://github.com/BikeNetKit/BikeNetLib>`__, part of `BikeNetKit <https://bikenetkit.org>`__.

When to use
-----------

BikeNetLib provides utilities for working with bicycle networks, from OpenStreetMap custom filters for selecting protected bicycle infrastructure, to functions for routing or importing/exporting network data. If you don't find a function that you need, please `let us know <https://github.com/BikeNetKit/BikeNetLib/issues>`__ or help us implement it.

Setup and use
-------------

To set up BikeNetLib, see the :doc:`installation` page.
To use BikeNetLib, the :doc:`getting_started` page
is a good place to start. Various usage examples are walked through on the :doc:`usage` page. For technical documentation, consult the :doc:`reference_user`.

Origin
------

The source code is inspired by different origins, mostly including code from research projects in the BikeNetKit family.
